## 包含内容

- `xinpin-youshu-demo.pptx`：16:9 单页演示文稿，已嵌入首页动效，并设置自动循环播放。
- `xinpin-youshu-homepage.mp4`：1920×1080，24 fps，约 8 秒，H.264 高清首页动效，无音轨。
- `使用说明.txt`：插入现有 PPT 与播放方法。

首页采用陨石视频背景与纯白悬浮 Logo。

## 使用方法

直接打开 PPT 并进入放映模式。如演示软件未自动播放，请单击视频。

插入现有 PPT：选择“插入 → 视频 → 此设备”，选中 MP4，然后按需设置自动播放、循环播放。

视频展示首页视觉与动画。输入问题、问询和项目切换需使用单独的网页演示。
